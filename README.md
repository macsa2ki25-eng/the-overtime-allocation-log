# 割り振り変更簿システム

学校現場の「勤務時間の割り振り変更」を管理するためのウェブシステムです。
会議等で発生した勤務超過時間を教職員に**付与**し、各教職員はためた時間を
勤務時間内の休みとして**利用**できます。付与・利用とも**管理職の承認**で確定します。

Google スプレッドシート + Google Apps Script (GAS) だけで動くため、

- **サーバー契約・費用が一切不要**(学校のGoogleアカウントがあれば動く)
- **データはすべてスプレッドシートに保存**(後任者がExcel感覚で直接確認・修正できる)
- **プログラミングの知識がない後任者でも運用できる**(年次更新もボタン1つ)

という、人事異動のある職場での引き継ぎを最優先にした構成になっています。

## 主な機能

| 機能 | 内容 |
|---|---|
| 付与 | 管理職・主任が会議等の発生日・時間帯を入力し、参加した教職員へ5分単位で付与(勤務時間**外**の分のみ算定) |
| 利用 | 教職員が取得日・時間帯を入力して申請(勤務時間**内**の分のみ算定)。残時間を超える申請は不可 |
| 承認 | 付与・利用とも管理職の承認で確定。申請時に管理職へ、承認/却下時に本人へメール通知(画面でも確認可) |
| マイページ | 自分の残り時間(前年度繰越/今年度の内訳つき)、累積付与・累積利用、承認待ちの確認 |
| 割り振り変更簿 | 累積超過時間・累積利用時間・残り時間と全履歴の一覧 |
| 日別一覧 | 付与日別・利用日別に、時間帯と時間を表示 |
| 管理ページ | 管理職のみ。承認待ち処理・全職員サマリ・全履歴・日別(全員)・名簿管理・設定 |
| 取消 | 誤入力時、管理職が承認済みの付与・利用を取消(行は消さず記録が残る) |
| 年次更新 | ①年度切替(残時間を繰越し、履歴をバックアップして削除) ②前年度繰越分の失効(6月頃) |

前年度繰越分と今年度分は**区別して管理**され、利用時は繰越分から自動的に先に
充当されます。このため、6月に繰越分を失効させても今年度の残りがマイナスに
なることはありません。

## 仕組み

```
教職員のスマホ/PC のブラウザ
        │  (ウェブアプリのURLを開き、名前+PINでログイン)
        ▼
Google Apps Script ウェブアプリ  ←─ メール通知(Gmail)
        │
        ▼
Google スプレッドシート(設定・名簿・付与記録・利用記録・通知ログ)
```

## リポジトリ構成

```
src/
  appsscript.json   GASプロジェクトの設定(タイムゾーンなど)
  Code.gs           入口・認証・データアクセスの共通処理
  Logic.gs          時間計算などの純粋ロジック(単体テストあり)
  Api.gs            一般ユーザー向けAPI(マイページ・申請)
  Admin.gs          管理職向けAPI(承認・取消・名簿・年次更新)
  Notify.gs         メール通知
  Setup.gs          初期セットアップ(シート自動作成)
  index.html        画面の枠組み
  style.html        デザイン(CSS)
  script.html       画面の動作(JavaScript)
docs/
  01_セットアップ手順.md      ゼロから動かすまで(非エンジニア向け)
  02_操作マニュアル.md        教職員・主任・管理職それぞれの使い方
  03_運用・引き継ぎマニュアル.md  年次更新・名簿・トラブル対応・異動時の引き継ぎ
  04_仕様書.md               データ構造・計算ルール(技術者向け)
tests/
  logic.test.js     時間計算のテスト(node tests/logic.test.js)
  balance.test.js   残時間計算のテスト(node tests/balance.test.js)
```

## はじめかた

[docs/01_セットアップ手順.md](docs/01_セットアップ手順.md) を上から順に
進めてください。所要時間はおよそ30〜60分です。プログラミングの知識は不要で、
ファイルの中身をコピーして貼り付ける作業が中心です。

## 開発者向けメモ

- コードを修正したら `node tests/logic.test.js` と `node tests/balance.test.js` を実行してください。
- 仕様の詳細は [docs/04_仕様書.md](docs/04_仕様書.md) を参照してください。
