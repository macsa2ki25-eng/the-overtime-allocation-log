# 01 セットアップ手順(ゼロから動かすまで)

プログラミングの知識がなくても進められるよう、すべての手順を順番に書いています。
所要時間の目安は 30〜60 分です。

---

## 0. 事前準備: どのGoogleアカウントで作るか(重要)

このシステムは「作ったGoogleアカウント」がデータの持ち主になり、
メール通知もそのアカウントから送信されます。

> **強い推奨: 個人アカウントではなく、学校の共用アカウント(例: 教務用アカウント、
> 役職アカウント)で作成してください。**
> 共用アカウントで作っておけば、担当者が異動しても**アカウントのパスワードを
> 引き継ぐだけ**で済み、作り直しや移行作業が一切不要になります。
> (個人アカウントで作った場合の引き継ぎ方法は
> [03 運用・引き継ぎマニュアル](03_運用・引き継ぎマニュアル.md) に書いてあります)

- Google Workspace(学校ドメイン)のアカウントでも、無料の Gmail アカウントでも動きます。
- 無料アカウントの場合、通知メールの送信上限は 1日100通です(Workspaceは1,500通)。
  通常の学校規模なら十分です。

## 1. スプレッドシートを作る

1. 上記のアカウントで Google にログインする
2. https://sheets.new を開く(新しいスプレッドシートが作られる)
3. 左上の「無題のスプレッドシート」をクリックし、名前を
   **「割り振り変更簿」** などに変更する

## 2. Apps Script エディタを開く

1. スプレッドシートのメニューから **「拡張機能」→「Apps Script」** を選ぶ
2. 新しいタブでスクリプトエディタが開く
3. 左上の「無題のプロジェクト」をクリックし、名前を「割り振り変更簿」に変更する

## 3. プログラムを貼り付ける

このリポジトリの `src` フォルダにある 10 個のファイルを、エディタに作って貼り付けます。

### 3-1. タイムゾーン設定(appsscript.json)

1. エディタ左側の歯車アイコン **「プロジェクトの設定」** をクリック
2. **「「appsscript.json」マニフェスト ファイルをエディタで表示する」にチェック**を入れる
3. 左側の「エディタ」(< > アイコン)に戻ると `appsscript.json` が表示されている
4. その中身を全部消し、`src/appsscript.json` の内容を貼り付けて保存(Ctrl+S / ⌘+S)

### 3-2. スクリプトファイル(6個)

最初からある `コード.gs` は名前を `Code` に変えて使います
(ファイル名の右の「︙」→「名前を変更」)。

| エディタで作るファイル | 貼り付ける内容 | 作り方 |
|---|---|---|
| `Code.gs` | `src/Code.gs` | 既存の「コード.gs」を改名 |
| `Logic.gs` | `src/Logic.gs` | 「ファイル」横の **+ → スクリプト**、名前は `Logic` |
| `Api.gs` | `src/Api.gs` | 同上、名前は `Api` |
| `Admin.gs` | `src/Admin.gs` | 同上、名前は `Admin` |
| `Notify.gs` | `src/Notify.gs` | 同上、名前は `Notify` |
| `Setup.gs` | `src/Setup.gs` | 同上、名前は `Setup` |

※ 名前を入力すると自動で `.gs` が付きます。中身は**元から入っている1行を消してから**全文を貼り付けてください。

### 3-3. HTMLファイル(3個)

| エディタで作るファイル | 貼り付ける内容 | 作り方 |
|---|---|---|
| `index.html` | `src/index.html` | **+ → HTML**、名前は `index` |
| `style.html` | `src/style.html` | 同上、名前は `style` |
| `script.html` | `src/script.html` | 同上、名前は `script` |

※ HTMLファイルにも元からひな形が入っています。**全部消してから**貼り付けてください。

すべて貼り付けたら **Ctrl+S(⌘+S)で保存** してください。

## 4. 初期セットアップを実行する(シートの自動作成)

1. スプレッドシートのタブに戻り、**ページを再読み込み**する(F5)
2. 数秒待つと、メニューに **「割り振り変更簿」** が追加される
3. **「割り振り変更簿」→「初期セットアップ(初回のみ)」** をクリック
4. **初回は「承認が必要です」というダイアログが出ます。** 以下の通り進めてください:
   1. 「権限を確認」をクリック
   2. 自分のアカウントを選択
   3. 「このアプリは Google で確認されていません」と表示されたら、
      左下の **「詳細」→「割り振り変更簿(安全ではないページ)に移動」** をクリック
      (自分で作ったプログラムなので問題ありません)
   4. 「許可」をクリック
5. もう一度 **「割り振り変更簿」→「初期セットアップ(初回のみ)」** をクリック
6. 「初期セットアップが完了しました」と表示されれば成功。
   「設定」「名簿」「付与記録」「利用記録」「通知キュー」「通知ログ」の6シートが作られ、
   通知メールを1分ごとに自動送信する設定も入ります

> **プログラムを更新したあとは、もう一度この「初期セットアップ」を実行してください。**
> 新しく必要になったシートや自動送信の設定が追加されます(既存のデータは消えません)。
> 状況はメニューの「セットアップ状況の確認」で点検できます。

## 5. 名簿に自分(管理職)を登録する

1. 「名簿」シートを開く
2. `T001` の行があるので、**氏名を自分の名前に、PINを自分だけの数字(4〜8桁)に**書き換える
   (役職は「管理職」のまま、状態は「在籍」のまま)
   ※シートに書いたPINは、最初のログイン時に自動で暗号化された表記(#で始まる
   長い文字列)に置き換わります。以後PINがシート上に見えることはありません
3. メールアドレス欄に自分のアドレスを入れると、申請があったときに通知メールが届きます
4. `T002` の行は記入例です。そのまま残しても(状態が「停止」なのでログインできません)、
   行ごと削除しても構いません

> 他の教職員の登録は、あとでウェブ画面の「管理」→「名簿」からでも、
> このシートに直接書き込んでもできます。IDは `T003`、`T004`…のように
> 重複しないように付けてください。

## 6. ウェブアプリとして公開(デプロイ)する

1. Apps Script エディタに戻る
2. 右上の **「デプロイ」→「新しいデプロイ」** をクリック
3. 左の歯車アイコン →「**ウェブアプリ**」を選ぶ
4. 次のように設定する:
   - 説明: 「割り振り変更簿」など(自由)
   - **次のユーザーとして実行: 自分**
   - **アクセスできるユーザー: 全員**
     ※「全員」にしてもデータは見えません。アプリを開くのに Google ログインが
     不要になる、という意味です。本人確認はアプリ内の名前+PINで行います。
5. 「デプロイ」をクリック
6. 表示された **「ウェブアプリ」のURL(https://script.google.com/macros/s/.../exec)をコピー**する
   — これが教職員に配るURLです

## 7. 動作確認チェックリスト

コピーしたURLをブラウザで開き、順に確認してください。

- [ ] ログイン画面に自分の名前が出る → 設定したPINでログインできる
- [ ] マイページに「残り合計 0分」と表示される
- [ ] 「付与申請」タブで、発生日=今日、時間帯=17:00〜17:30、事由=テスト、
      対象=自分 で起案できる(付与時間が30分と表示される)
- [ ] 「管理」タブ →「承認待ち」に表示され、「承認」できる
- [ ] マイページの残り合計が 30分 になる
- [ ] 「利用申請」タブで 16:30〜17:00 を申請 → 利用時間30分と表示される
- [ ] 「管理」→「承認待ち」で承認 → 残り合計が 0分 に戻る
- [ ] (メールアドレスを登録した場合)承認依頼・結果のメールが届いている
      ※届かない場合は「通知ログ」シートでエラーを確認
- [ ] テストで作ったデータは「管理」→「全履歴」から「取消」しておく
      (または気にせずそのまま運用開始しても問題ありません)

## 8. 教職員への展開

1. 「管理」→「名簿」から全教職員を登録する(登録時に初期PINが自動発行され、
   一度だけ表示されるので控えておく)
2. ウェブアプリのURLと各自の初期PINを配布する
   (URLはブラウザのブックマークやスマホのホーム画面に追加してもらうと便利)
3. 各自に最初のログイン後、マイページからPINを変更してもらう

## 9. プログラムを更新したときの再公開

コードを修正した場合は、保存しただけでは公開中の画面に反映されません。

1. エディタ右上の「デプロイ」→「**デプロイを管理**」
2. 鉛筆アイコン(編集)をクリック
3. バージョン: **新バージョン** を選んで「デプロイ」

**URLは変わりません**ので、再配布は不要です。
