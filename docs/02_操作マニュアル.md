# 02 操作マニュアル(教職員・主任・管理職)

## 共通の基本

### ログイン

1. 配布されたURLをブラウザ(スマホ可)で開く
2. 自分の名前を選び、PIN(暗証番号)を入力して「ログイン」
3. PINを5回連続で間違えると5分間ログインできなくなります
4. PINを忘れたら管理職に連絡してください(管理職が「PIN初期化」で新しいPINを
   発行できます)。PINは暗号化して保存されるため、管理職を含め誰も他人のPINを
   見ることはできません

### 申請が「通信エラー」になったとき

同じ内容(同じ人・同じ日・同じ時間帯・同じ事由)の申請は**二重に登録されません**。
もう一度申請すると「すでに同じ内容が登録されています」と表示され、前回の申請が
きちんと登録されていたことが分かります。心配なときは右上の「更新」を押して、
マイページの「承認待ちの自分の申請」を確認してください。

なお、承認依頼のメールは申請の直後ではなく、1分ほど後にまとめて送信されます。

### 表示の更新について

表示を速くするため、一度読み込んだ内容は数分間そのまま使い回されます。
自分が操作した内容はすぐ反映されますが、**他の人の申請・承認**が画面に
見えないときは、右上の **「更新」ボタン** を押すと最新の状態を取り直せます。

### 時間の数え方(重要)

勤務時間は標準で **8:30〜17:00** です(設定で変更可)。

- **付与**(超過時間をためる)は、入力した時間帯のうち**勤務時間の外**の部分だけが数えられます。
  - 例: 8:20〜8:30 と入力 → **10分** 付与
  - 例: 17:00〜18:00 と入力 → **60分** 付与
  - 例: 8:00〜9:00 と入力 → 勤務時間外は8:00〜8:30なので **30分** 付与
- **利用**(ためた時間で休む)は、入力した時間帯のうち**勤務時間の中**の部分だけが数えられます。
  - 例: 16:30〜17:00 と入力 → **30分** 利用
  - 例: 16:30〜17:30 と入力 → 勤務時間内は16:30〜17:00なので **30分** 利用
- 入力は**5分単位**です。画面に算定結果が自動表示されるので、申請前に確認できます。

### 前年度から繰り越した時間

- 前年度の残り時間は、新年度も**6月頃まで**使えます(管理職が失効処理をするまで)。
- 利用すると**繰越分から自動的に先に**使われます。自分で選ぶ必要はありません。
- マイページで「前年度繰越の残り」と「今年度分の残り」をいつでも確認できます。

### 申請の状態

| 状態 | 意味 |
|---|---|
| 承認待ち | 入力済み。管理職の承認待ち(残時間にはまだ反映されない) |
| 承認済み | 確定。残時間に反映されている |
| 却下 | 管理職が認めなかった(理由はメール・画面で確認) |
| 取下げ | 本人(または起案者)が承認前に取り下げた |
| 取消 | 承認後に管理職が無効にした(誤入力の訂正など) |

## 教職員ができること

### マイページ

- **残り利用時間**(合計と、前年度繰越/今年度の内訳)
- 累積超過時間(付与された合計)・累積利用時間
- 自分の承認待ち申請の確認と**取り下げ**
- PINの変更(画面下部の「PIN(暗証番号)を変更する」)

### 利用申請(割り振りを取る)

1. 「利用申請」タブを開く
2. 取得日・時間帯(5分単位)を入力 — 画面に利用時間が自動表示される
3. 「この内容で申請する」→ 確認して OK
4. 管理職が承認すると確定し、メール登録があれば結果が届く

※ 残り時間(承認待ちの利用分を除く)を超える申請はできません。

### 日別一覧

自分の記録を「利用日別」「付与日別」に切り替えて、日付ごとの時間帯・時間・合計・
承認状況を確認できます(自分の履歴の確認はこのタブです)。
累積超過時間・累積利用時間・残り時間はマイページに表示されます。

## 主任ができること(教職員の機能に加えて)

### 付与申請(超過時間の割り振りの起案)

1. 「付与申請」タブを開く
2. 会議等の**発生日**と**時間帯**を入力(勤務時間外の部分が自動算定される)
3. **事由**(会議名など)を入力
4. 参加していた**教職員を選択**(自分も参加していれば自分も選ぶ)
5. 「この内容で起案する」→ 確認して OK
6. 選んだ全員に同じ分数が付与申請され、管理職の承認後に確定します

画面下部の「これまでの付与の履歴を見る」で、自分に付与された分の承認状況・
処理結果を確認できます。
自分が起案した承認待ちの付与は、マイページから取り下げできます。

## 管理職ができること(上記すべてに加えて)

「管理」タブにすべての管理機能があります。

### 承認待ち

- 付与は会議ごとにまとまって表示され、「全員を承認/却下」も1人ずつの処理もできます
- 利用は申請ごとに、本人の残り時間を確認しながら承認/却下できます
- 却下時は理由を入力できます(本人に通知されます)
- 残り時間が不足する利用は承認できません(エラーが表示されます)

### 全体サマリ

全職員の繰越・付与・利用・残り時間・承認待ちが一覧できます。

### 日別(全員)

全職員の記録を利用日別・付与日別に表示します。
「この日に誰が何時から何分利用したか」が一目でわかります。

### 全履歴

種別・状態・教職員で絞り込みできる全記録の一覧です。
**承認済みの行は「取消」できます**(誤入力の訂正用)。

- 取消しても行は消えず「取消」状態で記録が残ります
- 付与を取り消すと残時間が減ります。すでに使われていてマイナスになる場合は
  警告が出ます(それでも実行するか選べます)
- 利用を取り消すと残時間が戻ります(繰越分の失効後は、繰越分の充当は戻りません)

### 名簿(年度途中の変更用)

このページでできるのは、**残り時間・ID・履歴に影響しない変更だけ**です。
3月末〜4月の人事異動はここではなく「年次更新」タブで行ってください
(3〜4月は画面上にも注意が表示されます)。

- **教職員を追加**(年度途中の着任): 初期PINが自動発行され、一度だけ表示されます
- **役職・メール・備考の変更**: 該当者の「変更」ボタンから
- **在籍状態の切替**: 産休・育休・休職・年度途中の転出は「停止にする」。
  ログインできなくなるだけで残り時間と履歴は保持され、復帰したら「在籍に戻す」だけです
- **氏名の修正**: 改姓・入力ミスの訂正**のみ**。別の先生の名前に書き換えると、
  残り時間と履歴がその人のものになってしまうため、警告つきの別操作になっています
- **PIN初期化**: 忘れた人に新しいPINを発行して伝えます
  (PINは暗号化して保存されるため、画面やシートで確認することはできません)
- 誤操作防止のため、自分自身の役職変更・停止はできません

### 年次更新

「年次更新をスタート」ボタンを押すと、あとは画面の案内(具体例つき)に従って
進むだけで完了します。転出・転入の反映も案内の中で行えます。
詳しくは [03 運用・引き継ぎマニュアル](03_運用・引き継ぎマニュアル.md) を参照してください。

### 設定

学校名・勤務時間・メール通知のON/OFFを変更できます。

### 通知メールについて

- 付与・利用の申請があると、メール登録のある管理職へ承認依頼メールが届きます
- 承認・却下・取消されると、メール登録のある本人へ結果メールが届きます
- メールが不要な場合は「設定」でOFFにできます(画面内の表示だけで運用)
